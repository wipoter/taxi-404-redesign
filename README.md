# Taxi 404 — сучасний редизайн

Адаптивний редизайн сайту «Альянс Таксі 404» для Кропивницького.

## Можливості

- адаптивна верстка для комп’ютерів і смартфонів;
- клікабельні телефонні номери з логотипами операторів;
- пошук адрес із підказками;
- розрахунок автомобільного маршруту, відстані й орієнтовного часу;
- приблизний розрахунок вартості за тарифом;
- посилання на Google Play та App Store;
- QR-код для переходу до застосунку.

## Запуск

Відкрийте `index.html` у браузері. Для пошуку адрес і побудови маршруту потрібне інтернет-з’єднання.

## Дані маршрутизації

Пошук адрес і розрахунок маршрутів використовують відкриті картографічні сервіси на базі OpenStreetMap. Розрахована ціна є орієнтовною — остаточну вартість підтверджує оператор.
